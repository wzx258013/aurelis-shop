# AEQUO

Italian handmade footwear storefront.

## GitHub Pages

1. Create a new public GitHub repository, for example `aequo-site`.
2. Push this folder to the repository's `main` branch.
3. Open `Settings > Pages` and set the source to `GitHub Actions`.
4. The workflow publishes the site at `https://YOUR_USERNAME.github.io/aequo-site/`.

For a root address, create the repository as `YOUR_USERNAME.github.io` and change the workflow base path to an empty value.

GitHub Pages is free and globally available, but mainland China access can vary by network. A second deployment on Cloudflare Pages is recommended for a more resilient China-facing address.
